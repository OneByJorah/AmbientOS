## What This Is

Ambient operating system — desktop environment with dynamic theming, workflow automation, and system monitoring.

Built for operators who want a self-hosted solution they control.

## Quick Start

### npm

```bash
npm install ambientos
```

### Docker (recommended)

```bash
git clone https://github.com/OneByJorah/AmbientOS.git
cd AmbientOS
docker compose up -d
```

### From Source

```bash
git clone https://github.com/OneByJorah/AmbientOS.git
cd AmbientOS
npm install
npm run dev
```

## Features

- **Self-hosted** — no cloud dependencies, run on your own hardware
- **Docker Compose** — full stack deployment with one command
- **npm package** — install via npm
- **Dark theme** — operational, clean UI

- **Dynamic theming** — Catppuccin-inspired color system with real-time theme switching
- **Workflow automation** — trigger-based task automation
- **System monitoring** — CPU, memory, disk, and process monitoring
- **Desktop environment** — lightweight, customizable UI
- **npm package** — install via npm
- **Cross-platform** — Linux, macOS, Windows support

## Tech Stack

- **Runtime** — Node.js, npm
- **Deployment** — Docker Compose, npm install
- **Configuration** — environment variables, config files
